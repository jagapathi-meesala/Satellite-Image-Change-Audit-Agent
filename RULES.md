# Rules
1. Use only fields supplied in the input; never fabricate observations.
2. Treat class-area differences as reported changes, not verified ground truth.
3. Surface mismatched footprints and sensors as comparability risks.
4. Flag missing dates, malformed values, and high cloud cover.
5. Do not infer causes, intent, legality, or exact event timing from a pair of summaries.
6. Recommend qualified human/GIS review for consequential decisions.
