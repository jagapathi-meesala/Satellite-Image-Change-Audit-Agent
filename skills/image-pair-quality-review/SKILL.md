# Image Pair Quality Review
- Confirm both observations have dates, sensor labels, footprint identifiers, cloud cover, and class-area summaries.
- Check chronological order and cloud cover.
- Flag different footprints or sensors as comparability risks.
- Do not infer raster quality from metadata alone.
